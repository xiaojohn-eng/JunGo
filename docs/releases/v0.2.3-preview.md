# JunGo v0.2.3-preview

JunGo 提供 Android 客户端、Apple Silicon Mac 菜单栏程序和 Linux 控制/设备服务。此次预览版首次提供可下载安装的多平台构建包，资源与许可证随包提供。安装和首次配对步骤见 [下载与部署指南](../download-install.md)。

## 更新

- 已配对的 Mac 可以修改显示名称；控制服务和本机同步更新，保留原设备 ID、私网 IP 和稳定主机名。升级已有自托管部署时，先更新控制服务，再更新 Mac 客户端。
- 从构建依赖中移除 GPLv2-only `go-lzo`。OpenVPN 配置使用 `comp-lzo: yes` 或 `adaptive` 时会在加载时明确报错；未使用 LZO 的连接可继续使用。
- Mac 发布构建会去除编译机器的本地绝对路径，安装包中包含 Go 后台、图标和许可证。

## 预览版限制

Mac 包使用 ad-hoc 签名，未经过 Apple 公证，首次打开可能需要在“系统设置 → 隐私与安全性”中确认。Android APK 使用预览签名，不保证能覆盖由其他签名构建的旧安装。所有设备须连接自行管理的 JunGo 控制服务，各自使用独立的一次性配对码；发布包不包含可直接加入的服务器配置。该版本未完成长期电量、手机 5 GiB 传输等专项验收，详情见 [验证说明](../validation.md)。

发布前运行了 Go 内部模块与 CLI 测试、Mac 客户端 10 项检查、Android 38 项 Release 单元测试及 Lint；APK 签名和 16 KiB 对齐、Mac 镜像与签名、各包版本和许可证资源也经过检查。尚无本次发布包在外部 Android 真机上的安装验收。
